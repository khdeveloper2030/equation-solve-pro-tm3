១. សមីការដឺក្រេទី២ (ax² + bx + c = 0, a ≠ 0)

Δ = b² - 4ac
  • Δ > 0 : មានឫសពិតពីរផ្សេងគ្នា៖ x₁,₂ = (-b ± √Δ) / (2a)
  • Δ = 0 : មានឫសឌុបមួយ៖ x₁ = x₂ = -b / (2a)
  • Δ < 0 : មានឫសកុំផ្លិចឆ្លាស់គ្នាពីរ៖ x₁,₂ = (-b ± i√|Δ|) / (2a)
  • Vieta : x₁ + x₂ = -b/a , x₁·x₂ = c/a

២. សមីការដឺក្រេទី៣ (ax³ + bx² + cx + d = 0, a ≠ 0)

t³ + pt + q = 0 (x = t - b/3a)
  • p : p = (3ac - b²) / (3a²)
  • q : q = (2b³ - 9abc + 27a²d) / (27a³)
  • Δ₀ : Δ₀ = (q/2)² + (p/3)³
  • ប្រើវិធីសាស្ត្រ Cardano នៅពេល Δ₀ ≥ 0 និងរូបមន្តត្រីកោណមាត្រនៅពេល Δ₀ < 0 (៣ ឫសពិត)។

៣. ករណីពិសេស (Degenerate Cases)

bx + c = 0 | 0 = c
  • ប្រសិនបើ a = 0 និង b ≠ 0 ៖ សមីការក្លាយជាដឺក្រេទី១ x = -c / b។
  • ប្រសិនបើ a = 0, b = 0 និង c ≠ 0 ៖ សមីការគ្មានចម្លើយ (0 = c មិនពិត)។
  • ប្រសិនបើ a = 0, b = 0 និង c = 0 ៖ សមីការមានចម្លើយរាប់មិនអស់ (∀x ∈ ℝ)។
